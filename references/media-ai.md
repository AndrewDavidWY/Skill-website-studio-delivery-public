# 媒体与 AI 网站模块

仅按当前范围阅读对应部分。媒体清单和功能状态与真实内容一致，不用装饰性控件代替可用交互。

## 人物肖像素材

用户需要并选择董事长官网风格时，按需读[中英肖像提示词](portrait-prompts.md)。无参考照片时只交付提示词；生成后人工核对身份与年龄感，不保证完全还原。本方案建议透明标识 AI 创作，不能暗示真实采访、交易所出席或获奖。普通网站不强制使用 AI 肖像。

## 视频与音频

- 保持原比例和方向，封面/正文先可读；按需加载、暂停、失败回退、减少动态偏好，避免多个视频抢播。按媒体清单检查文件、Content-Type、必要 Range、浏览器真实播放与手机操作。
- 第三方媒体按需求提供官方 embed、原链接和不可播放 fallback；能嵌入不等于版权获准。来源时间/时区与采集时间分开；发布地不等于拍摄地，不从 IP 推定事实。
- 音频使用真实音源、标题、有依据的时长/章节、播放/暂停、进度/跳转、键盘与触屏路径。按需求提供转录或替代内容，不将不存在的文字稿标为完成。
- 持久播放先定义同一 tab 内导航与刷新/新 tab/跨域的边界，保证唯一音频实例并正确处理 asset 哈希变化。页面离开时清理 listeners、timers、observers 与 pending requests，缓存组件仅激活当前页。检查重复导航、Back/Forward、切语言、搜索跳页、状态恢复；不因一次播放成功就确认跨页状态正确。
- CDN 地址可读与页面实际播放分开；版权、公开范围、性能预算和存储按项目决定。大媒体不靠占位 URL 或漏文件通过构建。

## 图书与长文迁移

图书详情按范围承载简介、作者/版本、目录、可公开样章、语言、格式及真实阅读/下载/购买入口。封面卡片或翻页器不等于全文可读；没有内容/授权时说明可用范围，下载核对文件名、文件内容与大小。

迁移前记录稳定 ID、路径、锚点、正文校验、媒体和特殊块，非破坏导入；常规启动、保存和构建不能重新覆盖后续编辑。目录顺序与章节发布状态分开。保留旧锚点到章节映射，核对脚注往返及跨章引用。生成 ID 前预留显式 ID/原 HTML ID，重复显式 ID 报错。测试长标题、折叠箭头与窄屏；记录实际 viewport，不把 resize 调用成功当成手机截图。

译目录不等于译正文。本地书签说明只在本设备可用；恢复旧阅读位置前检查章节仍公开。

## AI / 语音 / 知识问答

先明确是视觉/语音原型还是接入后端、检索与可审核知识源。界面、浏览器语音、服务端对话、知识检索、引用与持久化分别列已实现/已验证/缺口，避免原型被理解为正式服务。

回答限定已授权、可公开的知识，标注可核对出处；库外或证据不足时明确未知，不编造政策、资格或承诺。按需求设置未知问题队列，经人工审核升级知识；普通网站不必保存提问或配置复杂审核。记录来源版本、更新责任和失效处理。

前后端权限隔离，私密内容不经检索或日志泄漏；工具动作与写入在项目授权内。收集语音/提问时明确留存、删除、访问和提示。按范围用已知/未知问题、过期来源、越权内容和后端失败验收，演示响应不是实际检索证据。
