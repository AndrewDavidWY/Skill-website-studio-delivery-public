# 多语言与路由 SEO

语言集合、URL 结构、默认语言、翻译责任与回退策略从当前项目确认，不固定双语或语言数量。主域名和部署模式未定时，不把临时地址写成正式 canonical。

## 内容状态与路由

按产品要求确定语言选择优先级，可采用显式 URL/参数、手动偏好、支持的浏览器语言、默认兜底；显式页面语言不能被偏好无提示覆盖。存储不可用仍能访问，不假定跨域共享偏好。手机语言标签在真实窄屏 viewport 逐语种检查。

每条内容按语言记录待译、译稿、已复核、已发布状态，说明来源版本；源文更新后识别译文是否过期。可用源文版本或规范化 fingerprint 关联；忽略不会影响正文的流程字段/格式噪声，保留旧译文可编辑，人工复核后恢复公开。核对导航、正文、日期/数字、按钮、图片说明和 SEO 字段，不以菜单或目录已翻译证明正文完成。

语言切换到同一内容的已发布译文。没有译文时按确认策略隐藏入口、明确回退提示或保留待译说明；不能把原文放到外语 URL 后声明等价译文。正文和附件分别标识真实语言，译标题不等于译音轨/文件。公开/撤回/过期策略与路由、索引统一，避免草稿、重复 fallback 或预览 URL 成为正式语言页面。

## head 与 sitemap 共同验证

按现有策略核对页面 lang、独立 title/description、canonical、hreflang、主域跳转和 sitemap。语言 alternate 指向可用且等价的页面，核查互相对应、状态码与目标内容；x-default 按已确认的默认/选择页策略配置。不为所有项目强制相同属性。

新增栏目或修改生成器前保存真实基线：全部现有 URL、canonical 关系和每条语言 alternate（包括已有 x-default）。以语义解析比较新旧 sitemap，不只计算新增 URL 或字符串搜索；原有关系须保留，范围内删除/改路由有理由，并按确认策略使用 redirect 或 404/410，撤回不强制重定向。同步核对 HTML head 与 sitemap，不能只验证其中一处。检查缓存/线上产物是否属于本次版本。

## 验收范围

检查每种已发布语言的首页、列表、详情、语言切换，以及未译/过期/缺失内容、旧路由与 404。小站可全量检查，大站覆盖变更、每类模板及关键旧页面，注明范围；sitemap 全量旧 URL/alternate 回归可单独执行。测试环境与正式 URL 分开，线上 HTTP/TLS 核对后再声明发布可用。
