# 发布与恢复记录

用于实际发布；PR-only 时发布相关项写“范围外/未执行”。不保存秘密、私人数据或账号凭据。

- 项目、目标环境、域名/路径：待填写。
- 本次授权动作与范围、排除项：待填写。
- 基线/候选远端 commit、PR、合并 commit：待填写；本地快照与远端提交分开。
- 本地检查/构建：待填写，附 revision、环境与结果。
- 真实浏览器：待填写，附 revision、viewport、交互和限制。
- 远端 CI：待填写，附对应 SHA/run；未触发写“未运行”。
- 构建产物：待填写，附清单/校验值与源码版本关系。
- 新增/redirect/retired 路由与限定管理清单：待填写。
- 发布目标、覆盖/删除清单、执行者与时间：待填写。
- 发布 run/上传结果：待填写；skipped 与 success 分开。
- 线上 GET/TLS/浏览器证据：待填写，附域名、路由、版本和检查时间。
- CMS 内容/数据版本与兼容性（如有）：待填写。
- 覆盖前私有备份、保留期限、恢复方式与授权范围：待填写。
- 回滚步骤、验证结果/未演练部分、失败停止条件：待填写。
- 依赖安全发现、其他未执行/未验证事项、责任与下一步：待填写。

正式站更新以线上证据确认；他人后续发布注明来源与时间，不归入本次执行。
