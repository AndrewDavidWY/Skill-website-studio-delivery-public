# 官网与原生内容适配验收

仅在本次涉及 App 内容服务时填写；未运行、阻塞与不适用分别记录。

- 网站提交 / 构建 / 线上入口版本：
- 客户端平台 / 源码版本 / 安装版本 / 设备与输入方式：
- 公开内容与语言范围；请求语言 / 实际正文语言：
- 稳定 ID 与旧收藏、读位、章节、偏好基线：
- 支持的 schema、旧字段回退和未知类型策略：
- 目录 → 正文 / 书目录 → 章节的 bytes/hash 校验范围：
- 图片原图 / 预览 / 离线重编码的校验关系：
- 搜索来源、索引 revision 与未覆盖项：
- 缓存写入前校验、取消 / 迟到响应 / 切语言证据：
- 独立包更新、中断、空间不足、错误 hash 与旧版仍可读证据：
- 全网络断开并重启后的正文、图片、章节和位置证据：
- 同身份签名覆盖升级与前后数据核对：
- 手机 / 宽屏 / TV / 桌面实际测过的交互与返回链：
- 不可变资源与索引实际上传顺序；固定 URL 版本窗口与有限重试：
- 地区 / 域名真实服务范围、公开产物敏感信息检查：
- 构建 / PR CI / 合并 / 上传 / 线上 GET / 安装 / 启动 / UI 各层结果：
- 回滚副本、有效期限、恢复范围及未验证事项：

每项附对应版本和证据位置，不放用户数据、设备标识、密钥或私有日志原文。
